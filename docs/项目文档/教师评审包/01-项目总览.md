# 项目总览

## 1. 项目定位

实验室管理平台是梦工厂人工智能社团内部使用的项目制协作平台。平台以成员和项目为主线，统一承接任务、进度、资料、物资、会议和 AI 能力，并通过 NAS、GitLab 等外部系统保存或承载实际资源。

## 2. 建设目标

- 为学生提供清晰的个人工作入口：参与项目、待办任务、提交进展、资料、会议和物资。
- 为项目负责人和组长提供任务分配、成员协作、进度跟踪和问题跟进。
- 为教师和管理者提供全局看板、项目下钻、成员统计、资源状态和审批信息。
- 建立一个可扩展的统一主干：唯一前端、唯一 API、统一 PostgreSQL、插件化业务模块。

## 3. 当前技术基础

- 前端：React 19、TypeScript、Vite。
- 后端：Fastify、TypeScript。
- 数据库：PostgreSQL。
- 工程：pnpm workspace Monorepo、Docker Compose。
- 模块：`core`、`projects`、`inventory`、`files`、`collaboration`、`ai`。

## 4. 当前状态

当前是“可运行原型 + 主干重构阶段”。项目、成员、任务、项目树、进度汇报、项目笔记、物资基础流程、文件、会议和 AI 已有代码基础；项目链接字段、完整看板、多维统计、问题闭环、资源管理和权限收口仍需继续开发。

## 5. v1.0 边界

必须完成：角色化看板、项目和任务闭环、物资申请审批、资料与知识库基础能力、会议通知、AI 基础问答、统一权限和部署演练。

后续完成：工资/经费完整管理、场地/存储柜管理、正式 NAS 双向同步、本地模型、Agent、对外宣传和多实验室隔离。
