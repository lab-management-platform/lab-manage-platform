# 数据库 ER 图说明

维护源文件：[数据库ER图.puml](./07-数据库ER图.puml)

## 1. 图的范围

图示覆盖 `core`、`projects`、`inventory`、`files`、`collaboration`、`ai` 六个 schema 的核心实体和关系。

## 2. 关键关系

- 用户通过项目成员关系进入项目。
- 项目拥有负责人、导师、任务、资料、物资申请和会议。
- 任务支持负责人、评论和进度汇报。
- 物资通过类别决定是耗材领用还是器材借还。
- 项目文档地址和项目仓库地址保存在项目主表，作为外部资源导航字段。
- 文件版本、会议通知和 AI 知识文档分别保持自己的生命周期。

## 3. 渲染

```powershell
plantuml .\docs\项目文档\07-数据库ER图.puml
```

ER 图是目标数据库设计图；当前代码和目标模型的差异以[数据库设计](./06-数据库设计.md)中的迁移说明为准。
