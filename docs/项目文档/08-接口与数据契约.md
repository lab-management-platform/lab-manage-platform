# 接口与数据契约

## 1. 统一规则

- 前端只调用主仓库 API。
- 新接口先更新契约，再实现路由和页面。
- 所有项目接口执行项目权限校验。
- 项目对象统一返回 `documentUrl`、`repositoryUrl`，空值允许为 `null`。

## 2. 项目接口

```text
GET    /projects
POST   /projects
GET    /projects/:id
PATCH  /projects/:id
GET    /projects/:id/members
POST   /projects/:id/members
PATCH  /projects/:id/members/:userId
GET    /projects/:id/tasks
POST   /projects/:id/tasks
PATCH  /projects/:id/tasks/:taskId
POST   /projects/:id/progress
GET    /projects/:id/reports
POST   /projects/:id/reports
```

项目创建/更新请求至少包含：`name`、`ownerUserId`、`advisorUserId`、`documentUrl`、`repositoryUrl`、`status`、`startsAt`、`endsAt`。地址字段只保存 URL，不代理外部系统权限。

## 3. 物资接口

```text
GET/POST /inventory/categories
GET/POST /inventory/materials
GET/POST /inventory/applications
PATCH   /inventory/applications/:id/approve
PATCH   /inventory/applications/:id/reject
PATCH   /inventory/applications/:id/consume
PATCH   /inventory/applications/:id/borrow
PATCH   /inventory/applications/:id/return
GET     /inventory/stock-movements
```

耗材使用 `consume`，器材使用 `borrow/return`；归还规则由物资类别决定。

## 4. 错误和审计

统一返回状态码、错误消息和请求追踪 ID；创建项目、修改负责人、分配任务、提交汇报、物资审批和器材归还必须写入审计日志。
