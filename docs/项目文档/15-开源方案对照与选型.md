# 开源方案对照与选型

## Keycloak：身份认证

采用 OIDC Authorization Code + PKCE。Keycloak 负责用户凭据、登录、密码策略、找回密码、2FA、会话和角色组；平台只保存业务用户资料和项目成员关系。

## OpenProject：项目协作参考

借鉴项目模块、工作包、成员角色、看板、时间线、文档、会议和通知的组织方式。平台保留实验室特有的项目树、教师点评、阶段汇报和项目上下文。

## Nextcloud：资料与 NAS 参考

借鉴文件版本、标签、共享、回收站、外部存储和权限模型。平台保存资料元数据、项目关联、权限和 NAS/外链地址，大文件不进入业务数据库。

## ERPNext：物资参考

借鉴物资申请、仓库、入库/出库/调拨、序列号和库存流水。平台按实验室规则区分耗材和器材：耗材领用后不归还，器材必须借还并追踪逾期。

## 采用边界

第一阶段以成熟产品为模型和设计参考，不直接嵌入完整业务系统；认证优先外置 Keycloak。只有在 NAS/服务器资源、运维人员和备份策略确认后，才增加 OpenProject/Nextcloud 等独立服务。
