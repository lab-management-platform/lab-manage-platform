# 重构数据迁移与验收

## 迁移顺序

1. 备份 PostgreSQL 和 NAS 元数据。
2. 导入用户业务资料，建立 Keycloak `sub` 映射。
3. 导入项目、成员、任务和进度报告。
4. 将旧 material 映射为物资类别和物资条目。
5. 将旧 stock movement 映射为不可变库存流水。
6. 导入文件元数据、版本和 NAS/外链地址。
7. 导入会议、通知、知识库文档和审计记录。

## 兼容策略

- 新旧接口在迁移期间并行，但新页面只调用 `/api/v1`。
- 旧密码只允许一次性迁移到安全哈希，迁移后立即失效。
- 项目地址字段为空不阻塞旧项目使用。
- 物资无法判断是否归还时默认标记为“需管理员确认”，不得自动生成错误归还状态。

## 验收场景

- 成员只能查看自己的任务和被授权的项目资料。
- 负责人可以分配任务并审核成员提交。
- 教师可从成员下钻到项目、任务、成果和资料。
- 耗材申请完成后无归还待办；器材申请完成后存在应还日期。
- 年度项目统计使用数据库范围查询并命中索引。
- 文件版本可追溯，NAS 地址不会被误当作数据库文件内容。
- OIDC 登录、退出、过期、重置密码、角色变更和会话撤销均可验证。
