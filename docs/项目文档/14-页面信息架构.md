# 页面信息架构

## 1. 一级导航

一级导航只保留：工作台、项目、物资、资料与知识库、会议与通知、AI 助手、管理中心。登录和个人设置属于账户入口，不作为业务一级导航。

## 3. 角色化入口

- 普通成员：我的项目、我的任务、资料、会议、物资申请和 AI。
- 项目负责人：在项目详情中增加任务分配、提交审核、成员管理和风险视图。
- 教师：增加全局成员/项目/物资下钻看板、点评和审核。
- 管理员：增加成员、物资、文件、AI、审计和系统配置。

## 4. 交互原则

- 列表 → 详情 → 子资源，避免所有功能堆在一级页面。
- 当前项目通过顶部上下文和面包屑贯穿项目相关页面。
- 复杂编辑使用抽屉或独立详情页；列表只保留查询和批量操作。
- 看板卡片由权限、查询、筛选器和下钻路由组成，首版代码注册，后续可配置化。
