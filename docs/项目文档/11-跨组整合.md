# 跨组整合

## 1. 统一原则

以主仓库为唯一前端、API 和数据库主干。外部项目只提供能力、字段和流程参考，不保留独立运行时。

## 2. 能力归并

| 来源 | 主仓库归属 |
|---|---|
| 平台组 | 内核、项目、看板、统一装配 |
| SmartWrite-AI | 项目笔记、文档编辑、知识沉淀 |
| tech-material | 物资类别、库存、审批、会议、文件和任务流程 |

## 3. 字段映射

- 项目负责人映射到 `owner_user_id`。
- 项目文档地址映射到 `document_url`。
- 项目仓库地址映射到 `repository_url`。
- 外部文件路径映射到 `files.lab_file` 的存储提供方和 NAS/外链字段。
- 外部物资统一映射到 `inventory.material_category`、`inventory.material` 和申请/流水模型。
