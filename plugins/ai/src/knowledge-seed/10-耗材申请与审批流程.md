# 耗材申请与审批流程

## 适用范围

本文主要描述**耗材类物资（不可归还）**的申请 / 审批 / 领用流程。
器材类借还请参考"器材借还与逾期提醒"文档。

## 申请入口

- 物资 → 物资目录（点击某条耗材卡片上的"申请"）。
- 或工作台 → "快捷提交" → "耗材申请"。
- 若在某个"项目上下文"下申请，系统会自动带上项目关联（project_id），后续可在项目物资视图中追溯。

## 申请单典型字段

| 字段 | 说明 |
| --- | --- |
| 耗材名称 / 物资条目 | 必须从现有物资目录选择，便于准确扣减库存。 |
| 申请数量 | 必须为正整数或符合计量方式的小数（视业务规则而定）。 |
| 用途说明 | 必填，简单说明"用在哪个实验 / 什么用途"，便于审批。 |
| 期望领用时间 | 可选，默认尽快。 |
| 关联项目 | 可选，若填写则项目详情可见。 |
| 紧急程度 | 普通 / 紧急，默认普通。 |
| 申请人 | 自动取当前登录用户，不可篡改。 |

## 流程（框架）

```
填写申请单 → 提交（状态：待审批）
    ↓
审批人（lab_admin / 项目 owner / 指定审批人，按落地规则）
   ├─ 批准 → 状态：已批准 → 进入"领用 / 出库"环节
   └─ 驳回 → 状态：已拒绝 → 附理由，申请人可修改后再次提交
```

## 审批角色（待落地最终确认，框架级说明）

- 一般耗材：由实验室业务管理员 `lab_admin` 或指定物资审批人审批。
- 项目专属耗材：可能需要项目 owner 先同意，再到 lab_admin 终审（具体流程视课题组配置）。
- 紧急 / 大额物资：可能需要 professor 或 admin 额外一级审批（流程配置化后支持）。

## 审批通过后

- 申请人会收到"审批通过"通知，在"我的申请"中可查看。
- 按实验室约定的方式（到库房领取 / 配送）完成实物领用。
- 实际发放时，管理员在"入库 / 出库 / 调拨"页面执行**出库登记**，扣减库存，并写入库存台账。

## 常见问题（框架）

| 问题 | 建议答复 |
| --- | --- |
| 可以批量申请多种耗材吗？ | 建议首版一单一种类或在申请单中支持多条明细，按具体实现。 |
| 提交后想修改怎么办？ | "待审批"状态可撤回再改；已批准的修改请联系审批人驳回后重提。 |
| 审批一般多久？ | 按实验室 SLA（建议文档化后写入知识库，如：1 个工作日内答复）。 |
| 拒绝后还能再提吗？ | 可以，根据拒绝理由修正后重新提交。 |
| 没有我要申请的物资？ | 先在物资目录搜索；如确实缺失，联系管理员新增并办理入库后再申请。 |
