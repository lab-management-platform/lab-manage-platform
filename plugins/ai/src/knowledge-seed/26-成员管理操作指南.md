# 26-成员管理操作指南

> 模块：账号与个人设置页（管理中心）
> 适用角色：**实验室管理员 / 平台管理员 / 超级管理员**（普通学生/教授看不到"新增成员/成员列表"面板）
> 权限要求：需具备 `user:write` 权限
> 功能入口：左侧导航栏「账号 👤」→ 页面下半部分"新增成员 / 成员列表"

## 一、进入管理面板

1. 登录后点击左侧导航栏的「账号 👤」。
2. 页面上半部分为"账户概览 + 个人设置"（所有用户可见）。
3. 页面下半部分为"新增成员 + 成员列表"的双栏管理区域，**仅 `user:write` 权限可见**，普通用户此区域不渲染。

## 二、新增成员（创建账号）

操作步骤：

1. 找到左栏「新增成员」面板（标题：User Provisioning）。
2. 按表单顺序依次填写 **6 个必填字段**：
   - **登录名**（username）：用户登录用的账号名，建议拼音+数字的组合，不可重复
   - **身份类型**（下拉）：学号 student_no / 工号 employee_no；**切换角色时会自动联动**：选学生→学号，选教授/管理员→工号
   - **学号 / 工号**：对应上面身份类型的真实编号，用于身份核验与展示
   - **显示名称**：界面上展示给其他人看的姓名（可以是中文名）
   - **角色**（下拉）：学生 student / 教授 professor / 实验室管理员 lab_admin，三选一
   - **初始密码**：至少 8 位，用户首次登录后建议自行修改
3. 确认全部字段无误，点击「创建账号」（primary-button 蓝色大按钮）。
4. 成功后表单会自动清空，成员列表中会出现新账号（若搜索框有内容，先清掉关键词再确认）。

常见问题：

- 「创建账号」按钮变灰不可点：检查是否漏填必填字段，或检查是否还未给该用户分配"登录名"。
- 学号/工号与身份类型不匹配：提交后后端会校验格式，报错时请修正后重试。

## 三、成员列表 & 搜索

1. 找到右栏「成员列表」面板（Role Matrix）。
2. 顶部工具栏：
   - **搜索框**：支持按「用户名、姓名、学号/工号」模糊搜索，输入关键词后列表实时过滤。
   - 「角色分级已启用」芯片：表示系统当前正在按角色做权限隔离。
3. 每条成员卡片显示的信息：
   - 姓名（加粗）
   - 下一行小字：登录名 · 身份类型 学号/工号
   - 右侧「角色」状态徽标（student / professor / lab_admin）+ 是否启用（active）
4. 列表为空 / 无匹配时显示 EmptyState：「暂无匹配成员 / 换个关键词试试，或先创建新账号。」

## 四、调整用户角色

1. 先在成员列表中定位要调整的人（可搜索）。
2. 找到他那行卡片的**角色下拉框**（注意：你自己的账号不会显示下拉和操作按钮，无法自助改角色）。
3. 在下拉中选择目标角色：
   - student → 学生
   - professor → 教授
   - lab_admin → 实验室管理员
4. 切换后**立即生效**（不需要点额外保存按钮），顶部角色徽标同步更新。

权限提示：

- student → professor / lab_admin：用户登录后将看到更多功能（审批中心、新增成员等）。
- 降级（如 lab_admin → student）：对应 `user:write`、`inventory:approve` 等管理权限会立刻撤销。
- 建议不要在别人正在使用系统时突然降级，以避免操作中途报错。

## 五、重置用户密码

适用场景：用户忘记密码、或管理员怀疑密码泄露。

步骤：

1. 在该用户的卡片行点击「重置密码」按钮（tertiary-button）。
2. 弹窗输入**临时密码（至少 8 位）**并确定。
3. 成功后把临时密码**通过安全的线下/邮件渠道告知用户**，提醒用户首次登录后立刻在"个人设置 → 修改密码"中改成自己的密码。

## 六、停用账号

适用场景：学生毕业 / 成员离职 / 违规账号暂时禁用。

1. 找到该用户的卡片行，点击最右侧「停用」按钮（带 ghost-tone 样式的 tertiary-button）。
2. 停用后：
   - 用户无法再登录平台（密码校验直接拒绝）
   - 历史数据**完全保留**（该用户的项目、任务、申请、文件均不会被删除）
   - 卡片状态徽标变为 muted 灰色

如需重新启用：目前版本停用不可自助反启用，需要联系平台管理员在数据库手动把 `active` 列改回 TRUE，或删除该账号后重新按同一名创建。

## 七、操作建议

1. 批量导入成员前，建议先规划好"登录名"命名规则（例如：姓名全拼+入学年），避免后期改名麻烦。
2. 重置密码后务必提醒用户改密，临时密码不要长期挂在账号上。
3. 谨慎使用「停用」：因为目前 UI 不支持反启用；如果只是短期离校，建议先保留账号，等回来后改密码即可。
4. 所有管理操作（新增/改角色/重置密码/停用）均会被审计日志记录，请按实际业务场景谨慎操作。
