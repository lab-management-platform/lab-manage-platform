# 快速开始：登录、演示账号、默认入口

## 访问地址（本地开发 / Docker 启动）

| 服务 | 地址 | 说明 |
| --- | --- | --- |
| Web 前端 | http://localhost:5173 | 登录、工作台、所有业务页面 |
| API 后端 | http://localhost:3000 | 业务接口、插件注册、知识库写入 |
| 健康检查 | http://localhost:3000/health | 用于确认后端服务是否正常启动 |

## 演示账号

启动本地环境后，默认存在 3 个演示账号（仅用于本地联调，生产环境请及时修改或删除）：

| 账号 | 密码 | 系统角色 | 典型使用场景 |
| --- | --- | --- | --- |
| `admin` | `Admin@123456` | admin / super_admin | 管理中心全量功能、审计、角色配置 |
| `professor` | `Professor@123456` | professor | 教师视角：全局看板、点评审核、项目指导 |
| `student001` | `Student@123456` | student | 学生视角：申请耗材、任务协作、提交进度 |

> 密码规则提示：建议长度 ≥ 8 位，且包含大小写字母与数字。修改密码路径见"个人信息与密码管理"文档。

## 登录流程

1. 打开 Web 前端地址。
2. 在登录表单中输入用户名与密码。
3. 登录成功后自动跳转到工作台首页。
4. 如提示 `401 Unauthorized` 或被自动退出，通常是会话过期或数据库初始化异常，可重新登录或联系管理员检查服务状态。

## 登录后默认入口（首屏）

- 工作台"我的概览"：展示当前用户相关的项目数、待办任务数、待读通知数、待审批事项聚合。
- 顶部上下文选择器：可快速切换"当前关注的项目"，项目详情、物资申请、资料、会议等模块会自动带上项目上下文。
- 侧边栏一级导航：工作台、项目、物资、资料与知识库、会议与通知、AI 助手、管理中心（仅管理员可见）。

## 常见登录问题（排障框架）

| 现象 | 可能原因 | 建议处理方式 |
| --- | --- | --- |
| 提示用户名或密码错误 | 密码记错 / 账号停用 | 核对演示账号；联系管理员在管理中心重置密码 |
| 能登录但页面空白 | 前端构建产物缺失 / 路由异常 | 检查 `pnpm --filter @lab/web build` 或前端日志 |
| 登录后立即被踢出 | 会话 token 校验失败、数据库不可用 | 刷新页面重试；检查 API 服务健康状态 `/health` |
| 忘记密码 | 个人无法自助找回 | 联系 lab_admin / admin 在管理中心执行"重置用户密码" |
