# 器材借还与逾期提醒

## 什么是器材

"器材"指**需要归还的物资类别**（仪器、设备、工具、笔记本电脑、便携测试设备等）。
对应"物资类别"中的 `是否归还 = 是`。

器材与耗材的核心区别：

- 耗材：出库即消耗，不会生成"应还日期"。
- 器材：出库形成借用，必须在约定日期归还；超期会触发逾期提醒。

## 借用流程（框架）

```
1. 申请人在"物资目录"找到目标器材 → 点击"借用申请"
2. 填写：借用事由、期望借出时间、计划归还日期、关联项目（可选）
3. 提交 → 状态：待审批
4. 审批人（lab_admin / 设备管理员）
   ├─ 批准 → 状态：待领取
   └─ 拒绝 → 附理由
5. 实际领取器材 → 管理员登记"借出" → 状态：借用中，生成"应还日期"
6. 申请人使用完毕归还 → 管理员登记"归还" + 状态检查
   ├─ 正常归还 → 状态：已归还，台账写入归还记录
   └─ 异常（损坏 / 缺失配件） → 附异常说明 + 后续处理流程（维修 / 赔偿）
```

## 借用申请单字段

| 字段                        | 说明                                                      |
| --------------------------- | --------------------------------------------------------- |
| 器材条目（含序列号）        | 一物一码，必须精确到具体器材实例。                        |
| 期望借出时间 / 计划归还日期 | 决定借用时长与应还日期。                                  |
| 用途说明                    | 必填。                                                    |
| 使用地点                    | 实验室 / 外带外出（外出使用需要审批更严格，视规则而定）。 |
| 关联项目                    | 可选。                                                    |
| 申请人                      | 取当前登录用户。                                          |

## 逾期提醒

- **进入"借用中"状态后**，系统会在以下节点发出提醒（通知中心 + 我的待办）：
  - 应还日期前 1-3 天："您有一台设备即将到期归还，请注意时间。"
  - 应还日期当日：最终提醒。
  - 超过应还日期：每日提醒一次，或按策略升级提醒。
- 逾期信息会同时出现在管理员视图，便于主动跟进。

## 归还检查清单（管理员执行）

每次归还时建议检查：

- 外观是否完好、配件是否齐全（电池、充电器、线缆、保护箱）。
- 序列号是否与借出一致。
- 是否需要消毒 / 清洁 / 入库归位操作。
- 若存在异常，需要在系统中录入异常说明，并挂接到原借用单上。

## 常见问题（框架）

| 问题                   | 建议答复                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------ |
| 借用时间可以延长吗？   | 可以。在到期前提交"续借申请"，重新走审批；避免直接不还导致逾期。                     |
| 逾期会怎样？           | 会提醒升级；课题组是否有额外惩戒规则，取决于内部制度（建议写入"规章制度"文档）。     |
| 设备归还后坏了算谁的？ | 按归还检查记录判断；若借出前已损坏由管理员记录，借出后造成由借用人说明并按制度处理。 |
| 多人想用同一台怎么办？ | 后续可增加"预约"功能；当前建议由管理员在审批时协调，先借先得。                       |
