# 入库、出库、调拨与库存台账

## 谁可以操作

- 入库 / 出库 / 调拨通常由 `lab_admin`、物资管理员或授权的库房负责人执行。
- 学生 / 普通成员一般只有"查看"权限，不能直接修改库存。

## 入库

### 适用场景

- 新采购物资到货。
- 跨实验室 / 跨课题组调拨进入（目标侧）。
- 器材归还后状态异常需要补货或补登记。

### 入库单字段（框架）

| 字段 | 说明 |
| --- | --- |
| 物资条目 | 必须从物资目录中选，无法入库不存在的物资。 |
| 入库数量 | 正数，计量单位跟随类别设置。 |
| 批次 / 序列号 | 试剂批次号、器材序列号（按类别要求）。 |
| 来源 | 采购 / 调拨 / 其他（采购可附供应商与单号）。 |
| 存放位置 | 新位置或默认位置。 |
| 备注 / 有效期 | 过期提醒、安全说明等。 |
| 关联申请单（可选） | 如果是为某个已批准的申请补货，可关联以便追溯。 |

入库后：
- 物资条目当前库存自动增加。
- 在库存台账写入一条 `type = stock_in` 记录。

## 出库

### 适用场景

- 耗材申请被批准后，实际发放（最常见）。
- 内部调拨出（源侧）。
- 物资报废、过期处理（按"负入库"或专门的报废类型，最终落地再定）。

### 出库单字段（框架）

| 字段 | 说明 |
| --- | --- |
| 物资条目 | 必须已存在，且库存 ≥ 出库数量。 |
| 出库数量 | 正数，不可超过当前库存。 |
| 领用人 | 默认当前用户；实际代领时可由管理员改为对应成员。 |
| 关联申请单 | 若由"耗材申请 → 批准 → 出库"链路触发，必填以便追溯。 |
| 用途说明 | 简要记录。 |
| 备注 | 异常原因、报废说明等。 |

出库后：
- 当前库存自动扣减。
- 若扣减后 ≤ 预警阈值，自动触发低库存预警。
- 写入台账一条 `type = stock_out` 记录。

## 调拨

调拨 = "A 位置出库 + B 位置入库"的组合，用于同一种物资在**不同实验室 / 不同存放位置 / 不同课题组**之间的流转。

- 调拨完成后，台账应记录调拨双方的出入库动作，可通过"关联调拨单号"串联。
- 如跨课题组调拨，建议附带费用或资源归属约定（本期是否实现视财务边界而定）。

## 库存台账

### 台账能查到什么

- 每一次库存变动：谁、什么时候、动作（入 / 出 / 调拨 / 报废）、数量、关联申请单或调拨单、备注。
- 按物资、按时间范围、按操作人筛选。
- 作为审计与盘点时的唯一依据。

### 使用建议

- 发生"实物"与"台账"不一致时，以台账为起点回溯，并由管理员做"盘点调整"（框架功能，落地时再具体实现）。
- 所有台账操作不可删除；若操作错误，用**反向操作 + 备注**修正，保证操作链完整。

## 常见问题（框架）

| 问题 | 建议答复 |
| --- | --- |
| 入库后发现数量错了？ | 通过一次反向出库 / 入库调整，备注写明修正原因。 |
| 能否导出库存台账？ | 管理中心一般提供导出能力；首版若不支持，可由管理员从数据库导出。 |
| 为什么库存会变成负数？ | 正常流程下不允许出现负数；若出现，说明出库时未校验或有未登记的异常操作，需管理员回溯台账并补齐。 |
| 可以批量出库吗？ | 管理员界面可支持；按具体实现提供批量入口。 |
