# 通知中心与待办事项聚合

## 模块定位

通知中心 + 工作台"我的待办"是平台内"**被动提醒**"的总入口。
所有业务模块（项目、物资、文件、会议、AI、管理中心）都会将重要事件写入通知，并根据事件类型聚合到我的待办。

## 通知中心

### 典型事件类型（示例，不完整，随业务落地扩展）

| 来源模块 | 事件示例                         | 典型接收人                    |
| -------- | -------------------------------- | ----------------------------- |
| 项目     | 有新项目需要您立项审批           | professor / admin             |
| 项目     | 您被指派了新任务                 | 任务负责人（member / leader） |
| 项目     | 您有一条汇报即将到期             | 项目成员 owner / member       |
| 项目     | 您的汇报被退回修改               | 汇报提交人                    |
| 物资     | 您的耗材申请已通过 / 被拒绝      | 申请人                        |
| 物资     | 有耗材申请等待您审批             | 审批人（lab_admin 等）        |
| 物资     | 某耗材低库存预警                 | lab_admin / admin             |
| 器材     | 您借用的设备明天要到期           | 借用人                        |
| 器材     | 您借用的设备已逾期 N 天          | 借用人 + 管理员               |
| 文件     | 某文件共享给了我（若启用）       | 被共享成员                    |
| 会议     | 您被邀请参加会议                 | 被邀请人                      |
| 会议     | 会议 1 小时后开始                | 已确认参加的成员              |
| 会议     | 您负责的会议纪要还未提交         | 纪要负责人                    |
| AI 助手  | 您要求的查询已完成（若异步场景） | 当前用户                      |
| 管理中心 | 您的角色被调整                   | 目标用户 + admin              |
| 管理中心 | 新成员注册待审核（若启用）       | admin                         |

### 通知中心操作

- 查看通知列表（全部 / 未读）。
- 单条标记已读 / 全部标记已读。
- 点击通知：跳转到具体业务页面（例如"审批待办通知"→ 审批中心对应单据）。
- 清空已读（可选操作）。

## 我的待办（工作台聚合）

"我的待办"是通知中心的一个**更重动作、更高优先级**的子集。
典型待办类型：

1. 我需要**审批 / 决策**的：
   - 立项审批
   - 耗材申请审批
   - 进度汇报点评
   - 会议请假审批（若开启）
2. 我需要**提交内容**的：
   - 本周 / 本月进度汇报提交
   - 会议纪要提交
   - 被退回需要修改的任务 / 汇报
3. 我需要**跟进**的：
   - 今天 / 明天要到期的任务
   - 今天 / 明天要归还的器材
   - 今天 / 明天的会议（待确认参加的）

## 通知策略建议

- 通知**不只存在于站内**：未来可接入邮件、企业微信 / 钉钉 / 飞书等推送渠道。首版默认只推站内。
- 避免"通知轰炸"：
  - 同一事项的重复提醒要合并。
  - 用户可以对某些类型（如"会议开始前 1 小时提醒"）进行个性化开关。
  - 管理员视图可以看到"哪些用户长期不看通知"，可人工跟进。

## 与 AI 助手的关系

- AI 助手中当用户问："我今天有什么待办 / 要做什么"时，会把"我的待办 + 今日会议 + 逾期提醒"做一个汇总答复。
- 对于审批类待办，AI 会给出：单据摘要 + 跳转链接 + **不会自动审批**（审批类写操作需要用户在界面二次确认）。

## 常见问题（框架）

| 问题                   | 建议答复                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| 通知太多看不过来？     | 优先处理"我的待办"中的高优先级项；其余通知可批量标记已读。                                 |
| 收不到通知？           | 先检查通知中心是否已被批量标记已读；若确实缺失，联系管理员确认业务流程是否触发了对应事件。 |
| 误操作清空了通知？     | 业务事件本身还在（例如审批单不会消失），只是站内通知记录被清掉。                           |
| 可以关闭某一类通知吗？ | 建议提供个性化开关；首版若不支持，可由管理员做全局配置。                                   |
