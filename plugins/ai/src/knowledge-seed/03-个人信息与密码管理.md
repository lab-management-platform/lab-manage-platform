# 个人信息与密码管理

## 个人信息入口

登录后，个人信息与账号相关设置位于页面右上角的账户入口。典型可维护字段：

| 字段                   | 说明                                    | 是否可自行修改               |
| ---------------------- | --------------------------------------- | ---------------------------- |
| 用户名（username）     | 登录唯一标识                            | 不可修改                     |
| 显示名（display name） | 对外展示、申请单与会议中的身份名称      | 通常可改                     |
| 手机号 / 联系方式      | 紧急联系、通知触达                      | 通常可改                     |
| 系统角色               | student / professor / lab_admin / admin | 不可自行修改，仅管理员可调整 |
| 所在课题组 / 小组      | 成员归属                                | 通常可改或由管理员调整       |

## 修改密码

### 适用场景

已知当前密码，希望更换新密码。

### 建议路径

1. 右上角账户入口 → "修改密码"或"个人设置"。
2. 依次输入：当前密码、新密码、确认新密码。
3. 提交后即时生效，会话可能会被要求重新登录。

### 新密码建议规则

- 长度不少于 8 位。
- 同时包含大写字母、小写字母、数字。
- 避免使用生日、手机号、连续数字等过于简单的组合。
- 演示账号首次登录后建议尽快修改默认密码。

## 忘记密码

平台当前**不提供自助找回（邮箱 / 手机验证码）能力**。

### 处理方式

- 联系实验室业务管理员（`lab_admin`）或平台管理员（`admin / super_admin`）。
- 管理员在"管理中心 → 成员目录"中找到对应账号，执行"**重置用户密码**"操作。
- 重置完成后，管理员将临时密码告知用户，建议用户登录后第一时间自行修改为新密码。

## 账号停用 / 离职

- 账号的"启用 / 停用"状态只能由管理员操作。
- 被停用的账号无法登录，历史业务数据（申请、提交、会议纪要等）仍保留，审计与业务追溯不受影响。
- 若离开课题组或变更角色，由管理员统一调整角色或停用账号。

## 常见问题（框架）

| 问题                   | 建议答复（待具体实现落地后补全）                             |
| ---------------------- | ------------------------------------------------------------ |
| 能否修改用户名？       | 否。如需替换账号，建议新增账号并迁移项目成员身份。           |
| 多次输错密码会锁定吗？ | 具体锁定策略由部署配置决定；如果无法登录，请联系管理员重置。 |
| 修改后忘记新密码？     | 按照"忘记密码"流程处理。                                     |
| 管理员账号忘记密码？   | 由 super_admin 或运维侧通过数据库脚本重置。                  |
