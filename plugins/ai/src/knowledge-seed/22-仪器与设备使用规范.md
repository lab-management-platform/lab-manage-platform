# 仪器与设备使用规范

## 定位

本文档是**框架性条目**。实验室每一类具体设备（高压釜、离心机、生物安全柜、PCR 仪、共聚焦显微镜、低温冰箱等）的详细 SOP、注意事项、事故处置，请由仪器负责人在"公共资料 + AI 知识库"中为**每台 / 每一类设备**单独建一篇文档。

在具体文档缺失前，AI 会以通用规范 + "未在知识库查找到相应操作，酌情采纳"的方式答复，避免误操作。

## 通用使用规范（所有设备建议遵守）

### 1. 仪器使用前

- 确认自己具备**对应的专项培训 / 准入资质**（参考"实验室安全培训与准入要求"）。
- 查看仪器状态：上次使用记录、运行日志、是否存在故障标记。
- 确认使用时段：若有预约系统，先预约；若无预约，现场登记后使用。
- 确认耗材 / 试剂 / 管路齐全，避免中途中断。
- 对于低温 / 高温 / 高压类设备：提前检查冷却水源、排气、压力表、安全联锁。

### 2. 仪器使用中

- 保持专注，**不要长时间无人值守**；高风险设备（高压、高温、激光、生物安全）严禁离岗。
- 发现异常（异响、异味、报警、异常升温）：
  1. 第一时间停机（按设备 SOP 的停机步骤）。
  2. 切断电源 / 气源 / 热源（按设备特点）。
  3. 立即通知仪器负责人或实验室安全员，禁止自行拆修。
- 如发生泼洒、样品泄漏，按化学 / 生物泄漏处置 SOP 处理。
- 做好使用过程的关键参数记录（便于后续 AI 问答与排障）。

### 3. 仪器使用后

- 按要求清洁样品区、台面、配件，清理废液 / 废料。
- 关闭软件 → 关机（步骤视仪器而定：部分仪器要求先关软件、等冷却再断电）。
- 断电、关气 / 关水（按具体 SOP）。
- 填写运行日志：使用人、样品、起止时间、是否异常、后续预约人等。

## 预约与共享（框架建议）

- 若某些仪器使用频率高，建议有预约登记（线下预约本 / 后续平台提供"设备 / 场地预约"插件）。
- 使用冲突时：
  - 优先按预约时间顺序；
  - 没有预约时，由仪器负责人或 lab_admin 协调；
  - 紧急实验优先（如样品时效不可等待），但事后要补登记并与被插队的同学沟通。

## 故障与维护

| 情况 | 建议处理 |
| --- | --- |
| 日常轻微异常（提示错误、结果偶发异常） | 先记录现象 → 查常见问题 FAQ（若知识库有）→ 无法解决联系负责人。 |
| 明显故障（冒烟、着火、不启动、严重漏液） | 立即按紧急停机流程操作 → 通知仪器负责人 / 安全员 → 事故后补记录。 |
| 定期维护（换油、校准、清洁、计量检定） | 由仪器负责人按周期执行，建议登记在"公共资料 - 设备台账"。 |
| 维修（送外修、厂家上门） | 由 lab_admin / 管理员协调；维修期间在设备上挂牌，防止他人误用。 |

## 常见问题（框架，待各设备 SOP 细化）

| 问题 | 建议答复 |
| --- | --- |
| 我能用 XX 仪器吗？ | 先确认：1) 是否通过对应专项培训；2) 是否有可用时段；3) 仪器当前状态是否正常。 |
| 使用后忘关仪器怎么办？ | 马上返回处理；若已离开且无法返回，立即联系在实验室的同学或仪器负责人代为处理，事后补说明。 |
| 仪器坏了算我责任吗？ | 按实际情况：按 SOP 正常使用出现的故障属正常损耗；明显违规操作导致的按实验室制度处理。 |
| 能把仪器搬到别的房间用吗？ | 通常不建议；移动前必须经仪器负责人同意，并确保搬运过程不会损坏（特别是精密光学类）。 |
