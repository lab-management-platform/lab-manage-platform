# 物资目录与耗材分类

## 物资模块概览

物资模块覆盖**耗材**（不可归还）与**器材**（可归还）两类，流程区分如下：
- **耗材**：物资目录 → 申请 → 审批 → 领用（consume），库存随出库扣减。
- **器材**：物资目录 → 申请 → 审批 → 借出 → 归还（borrow → return），记录应还日期并可逾期提醒。

## 物资目录结构

物资按"类别 → 物资明细"两级组织：

### 物资类别（category）典型字段

| 字段 | 说明 |
| --- | --- |
| 类别名称 | 如"细胞培养耗材 / 通用化学试剂 / 仪器设备"。 |
| 是否归还 | 决定是耗材还是器材；同时决定后续流程。 |
| 计量方式 | 个 / 盒 / 瓶 / 台 / 套，用于申请单与库存统计。 |
| 序列号要求 | 器材类通常要求"一物一码（序列号）"，耗材可能不需要。 |
| 动态属性 | 类别级扩展字段，如：浓度、纯度、规格、厂家、型号、保质期要求。 |
| 预警阈值 | 低于该数量时进入"低库存预警"。 |

### 物资明细（material / 具体条目）

| 字段 | 说明 |
| --- | --- |
| 名称 | 正式、规范的名称，避免别名歧义。 |
| 所属类别 | 关联到上述 category。 |
| 规格 / 型号 / 厂家 | 便于精确搜索与采购。 |
| 当前库存数量 | 实际可用数量。 |
| 存放位置 | 实验室 / 楼层 / 房间 / 柜子编号，便于找到实物。 |
| 序列号 | 器材类一物一码。 |
| 备注 | 注意事项、使用限制、安全信息。 |

## 目录视图与检索

- 默认进入"物资目录"，可按类别筛选；支持按名称、规格、位置关键词搜索。
- 卡片 / 列表可展示：库存数量、是否接近预警阈值、存放位置缩略、申请按钮。
- 管理员可在"类别设置"中维护类别、计量方式、动态属性、预警阈值。

## 低库存预警

- 当某物资"当前库存 ≤ 类别预警阈值"时，会在以下位置提醒：
  - 物资目录中的物资卡片上标记"库存不足"。
  - 管理员 / lab_admin 工作台"异常提醒"卡片。
  - AI 助手查询库存时会高亮提示。
- 触发预警后，建议流程：lab_admin 发起采购（采购流程是否在本期实现待定）或调拨，然后通过"入库"操作增加库存。

## 常见问题（框架）

| 问题 | 建议答复 |
| --- | --- |
| 新采购的物资怎么录入？ | 走"新增物资条目 + 入库登记"两步；若类别不存在，先由管理员在类别设置中新增。 |
| 同一试剂有多种浓度怎么办？ | 建议拆成不同物资条目，或利用"类别动态属性"在搜索与申请时区分。 |
| 找不到我要的耗材？ | 先确认关键词；若确实未录入，联系管理员或实验室负责采购的同学补充。 |
| 能看到历史价格吗？ | 首版不含财务字段；如需要可在备注中记录，后续财务模块再补齐。 |
