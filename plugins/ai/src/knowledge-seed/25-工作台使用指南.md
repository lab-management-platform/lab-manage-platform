# 25-工作台使用指南

> 模块：工作台（Dashboard）
> 适用角色：学生 / 教授 / 实验室管理员 / 平台管理员
> 功能入口：左侧导航栏第一个模块「工作台 ◫」或登录后默认进入

## 一、进入工作台

登录成功后，系统会默认进入工作台。也可以任意时刻点击左侧导航栏的「工作台 ◫」图标回到本页面。工作台提供的是**跨项目聚合视图**，所有汇总数据均为你**权限范围内**可见的数据。

## 二、欢迎区（Hero Panel）

位置：页面最顶部的蓝灰色大卡片。

1. 显示欢迎语「欢迎回来，<你的姓名>」。
2. 右侧 4 张**统计卡片**（StatCard）：
   - 待审批：待处理的领用申请数量（金色强调）
   - 项目进行中：由服务端聚合的"进行中项目"数量
   - 低库存预警：库存低于阈值的物资种数（红色强调，建议优先补货）
   - 已批准：可见成员数量

## 三、快捷入口条（Command Strip）

位置：欢迎区下方的灰卡片。

1. 显示「教师视角 / 管理视角 / 成员视角」标签，对应你的当前角色。
2. 右侧三个大按钮，可**一键跳转到常用模块**：
   - 「查看我的项目」→ 跳转到项目目录页
   - 「进入审批中心 / 申请物资」→ 跳转到物资页（**根据你是否有审批权限动态切换文案**）
   - 「查看会议通知」→ 跳转到会议与通知页

## 四、组织概览（Drill-down 网格）

位置：快捷入口条下方。

4 个大卡片，点击可直接钻取到对应模块：

1. **成员与项目** → 跳项目目录（显示项目总数 + 项目→负责人→任务与成果 路径提示）
2. **物资与库存** → 跳物资管理（显示物资品种数 + 物资→库存→申请与借还 路径提示）
3. **资料与知识** → 跳文件资料（显示"NAS"标识 + 项目资料→文件版本→引用来源 路径提示）
4. **会议与进展** → 跳会议通知（显示通知条数 + 会议→参会→纪要与进度 路径提示）

## 五、项目概览 & 系统提醒（左右两栏）

### 5.1 项目概览（左栏）

- 显示最多前 4 个「进行中」的项目。
- 每条项目卡片可点击：点击后先**自动切换该项目为顶部导航的当前项目上下文**，再跳转到项目详情页。
- 卡片字段：项目名称 / 负责人姓名 / 项目周期（截止日期） / 「进行中」状态徽标。
- 无项目时显示 EmptyState：「暂无进行中的项目 / 创建或激活项目后，这里会展示...」。

### 5.2 系统提醒（右栏）

- 按时间倒序显示最近 4 条通知（公告、审批变动、会议提醒等）。
- 每条展示标题 + 摘要 + 发布时间（精确到分）。
- 无新通知显示「暂无新提醒」占位图。

## 六、重点任务 & 低库存预警 & 待审批申请（下方三栏）

### 6.1 重点任务

- 取最近更新的前 4 条项目任务，按更新时间倒序。
- 卡片展示：任务标题 / 指派人姓名（未指派显示"待指派"） / 状态徽标（todo / doing / done）。
- 可点击跳转项目详情。

### 6.2 低库存预警

- 取所有物资中 `stock <= warnStock` 的前 5 条。
- 显示：物资名称 / 「当前库存 X」 / 「预警阈值 Y」 / 状态徽标（danger 红色）。
- 点击跳物资目录页，可直接发起补货申请。

### 6.3 待审批申请

- 取状态为 `pending` 的前 4 条领用申请。
- 显示：申请单号 / 申请人 + 学号 / 申请时间 / 状态徽标（pending）。
- 有审批权限的用户点击直接进入审批中心。

## 七、使用小贴士

1. **顶部项目切换器**会影响工作台显示的数据：选"全部项目"=全量汇总，选具体项目=仅该项目范围内统计。
2. 工作台所有卡片都有对应的跳转路径，尽量从工作台钻取而不是靠长页面滚动找入口。
3. 如果你是教授/管理员：低库存预警 + 待审批申请是每日优先处理项，建议一登录就刷新一次工作台查看。
4. 通知未读数也会显示在顶部右侧铃铛图标上（与工作台"系统提醒"同步）。
