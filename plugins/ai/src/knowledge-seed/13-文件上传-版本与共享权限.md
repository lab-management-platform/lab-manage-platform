# 文件上传、版本与共享权限

## 文件模块的定位

文件资料模块承载"项目内部协作 + 公共资料沉淀 + 知识库答疑源"三种用途。

## 支持的文件格式（以当前实现为准）

- 文本类：`.txt` / `.md` / `.markdown` / `.json` / `.csv` / `.yaml` / `.yml` / `.log`
- 常用文档：`.pdf` / `.docx`（AI 知识库上传解析支持此两类）
- 其他格式（如图片、PPT、压缩包）建议先以"项目资料附件"形式上传（具体解析能力视版本实现而定）。

## 上传入口

- **项目资料**：项目详情 → "项目资料" Tab。文件自动携带 `project_id`，仅项目成员与管理员可见。
- **公共资料**：资料与知识库 → "公共资料"。全平台成员可浏览，常用于 SOP、规范、模板文件。
- **AI 知识库上传**：AI 助手 → "知识库管理"。上传文件会被解析文本后切分并灌入 `ai.knowledge_document`，用于 AI 答疑检索。

## 上传建议字段

| 字段                | 说明                                 |
| ------------------- | ------------------------------------ |
| 文件                | 本地选择。                           |
| 标题                | 默认取文件名，可改。                 |
| 分类 / 标签         | 便于后续搜索与 AI 召回。             |
| 版本号              | 可选（首版可能自动 v1 / v2 递增）。  |
| 描述                | 简要说明用途、适用实验、注意事项等。 |
| 关联项目 / NAS 路径 | 可选；NAS 路径用于外链引用大文件。   |

## 版本管理

- 若覆盖上传同名 / 同类文件：建议保留历史版本（由平台实现自动递增版本号）。
- 任意版本可单独下载、对比（首版可能仅提供下载，对比为后续增强）。
- AI 知识库文档若更新，会重新计算分块与 Embedding，确保检索到最新内容。

## 共享与访问权限（框架）

权限原则：**默认最小可见，逐级放开**。

| 场景                      | 默认可见范围                                                                  |
| ------------------------- | ----------------------------------------------------------------------------- |
| 项目资料（Project 上传）  | 该项目成员 + 相关管理员。                                                     |
| 公共资料                  | 平台所有登录成员。                                                            |
| AI 知识库文档（用于答疑） | 所有可使用 AI 助手的角色；但文档**内容维护**建议只对 lab_admin / admin 开放。 |
| 单个文件共享（外链）      | 可选功能，可设置有效期 / 密码 / 仅本组织（具体实现再定）。                    |

## 大文件（原始数据 / 测序 / 图像）处理建议

- **不建议直接上传大文件到业务库**（占用空间、备份困难、迁移麻烦）。
- 推荐做法：
  1. 原始大文件放在实验室自有 NAS / 对象存储中。
  2. 在平台的"NAS 资料索引"中登记**路径、描述、负责人、版本、权限**。
  3. 若希望 AI 可检索其中结论，可单独上传一份"摘要 / README.md"到 AI 知识库。

## 常见问题（框架）

| 问题                         | 建议答复                                                                   |
| ---------------------------- | -------------------------------------------------------------------------- |
| 文件上传失败怎么办？         | 检查文件大小限制、格式是否允许；若都没问题，联系管理员查看服务日志。       |
| 误删文件可恢复吗？           | 建议首版使用"软删除"，管理员可恢复；若实现为硬删除，需联系运维从备份恢复。 |
| 我想给外组同学看文件怎么办？ | 通过"共享权限"加其成员到项目，或使用带密码的文件外链（若该功能启用）。     |
| 多个项目都需要的 SOP 放哪？  | 建议放"公共资料"，并同步一份到 AI 知识库（答疑可以引用）。                 |
