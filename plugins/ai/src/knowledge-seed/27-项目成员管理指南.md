# 27-项目成员管理指南

> 模块：项目详情页 → 项目成员区块
> 适用角色：**项目 owner（负责人） / leader（组长）/ 实验室管理员 / advisor（指导者）**
> 普通 member 仅能查看成员列表，不可增删改成员角色。
> 功能入口：左侧「项目 ▣」→ 选中具体项目 → 向下滚动到「项目成员」区块（在项目详情下半部分）

## 一、查看项目成员

1. 登录后点击左侧「项目 ▣」进入项目目录页。
2. 通过顶部项目切换器或项目卡片点击，定位到你要管理的那个项目。
3. 页面详情的下半部分（在"进度汇报"面板上方）有「项目成员」标题区块。
4. 每位成员卡片展示信息：
   - 姓名（加粗）
   - 项目角色徽标：owner / leader / member / advisor / observer
   - 身份号一行小字：学号或工号（对应身份类型）
   - 加入时间（YYYY-MM-DD）

## 二、项目内角色说明

一个用户在项目里的身份由"项目角色"决定（独立于其系统角色 student / professor / lab_admin）：

| 项目角色 | 显示名 | 权限说明                                             |
| -------- | ------ | ---------------------------------------------------- |
| owner    | 负责人 | 最高权限：增删成员、改角色、改项目信息、删任务与笔记 |
| leader   | 组长   | 仅次于 owner：可加任务、改成员角色（但不能踢 owner） |
| advisor  | 指导者 | 可点评汇报、可改成员角色（只读升级通道）             |
| member   | 成员   | 做任务、写笔记、提交申请、参会                       |
| observer | 观察者 | 纯只读：不能改任何东西，只看项目进展与文档           |

owner 和 advisor 有 `canManageProject` 权限，页面上会出现「添加成员」表单和「改角色/移除」按钮。

## 三、添加项目成员

步骤：

1. 定位到「项目成员」区块左侧的**添加成员表单**（如果看不到，说明你在本项目中不是 owner/leader/advisor，没有权限）。
2. 填写 3 个字段：
   - **姓名（userName）**：必填，真实姓名或可辨认的显示名（用于前端展示）
   - **学号 / 工号（identityNo）**：必填，用于在后台匹配到该用户的系统账号；填错会匹配失败或加到错误的人身上，请务必核对
   - **项目角色（memberRole）**：下拉选择，默认 `member`；可改 `leader / member / advisor / observer`；**owner 只能通过"交接项目"方式变更，不能在这里直接加 owner**
3. 点击「添加成员」按钮（primary-button）。
4. 成功后下方成员列表会立刻出现该新成员，加入时间为当日日期。

常见问题：

- 提示"找不到该用户"：检查学号/工号是否和系统里的对得上。请先让管理员在「成员管理操作指南」模块里把人创建进系统账号，再添加为项目成员。
- 按钮灰色不可点：检查姓名或身份号是否为空。

## 四、调整项目成员角色

1. 在成员列表中找到要调整的那个人（卡片形式）。
2. 找到该行右侧的**项目角色下拉框**。注意：
   - `owner` 和 `advisor` 不允许被随便改角色，下拉框会隐藏或禁用。
   - 你自己如果是 member，也不会看到改角色下拉框。
3. 在下拉中选择：member / leader / advisor / observer
4. 选择后立即生效，该成员的角色徽标同步变为最新颜色。

权限规则：

- 不能把 owner 降级；需要交接项目请联系实验室管理员，在后端变更 ownerId。
- 不允许把非 owner 升为 owner（为了安全，避免误操作直接拿到项目最高权限）。
- advisor → leader 是允许的，advisor → member 也允许。

## 五、移除项目成员

适用场景：成员毕业、换组、或误加了错误的人。

步骤：

1. 在成员卡片行找到「移除」按钮（danger 风格或 ghost-tone tertiary-button）。
   - owner / advisor 本人没有移除按钮。
2. 点击后，该成员会立刻从项目成员列表中移除。
3. 移除的影响：
   - 该用户登录后左侧导航栏将看不到这个项目
   - 该用户之前创建的任务、笔记、进度汇报**历史数据仍保留**（只是不再是这个项目的活跃成员，不可以再写新内容）
   - 借用中/待审批的物资申请会被保留，需要管理员单独处理

## 六、小贴士

1. 一个用户可以同时是多个项目的成员，顶部「项目切换器」能在多个项目之间自由跳转。所以添加成员时不要担心"加了这个项目就不能在另一个项目"。
2. 建议把项目里**导师（教授）**设为 advisor，**直接管日程的学生**设为 leader，其他普通同学设 member。
3. 项目 owner 字段是与项目审批、删除、归档的核心权限绑定的，确定好后不要频繁改。
4. 误操作移除成员，可立即按同样的学号+姓名重新加回来，历史关联会自动续上。
