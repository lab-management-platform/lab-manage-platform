# 项目进度汇报与点评机制

## 为什么要提交进度汇报

- 为教授 / 导师、实验室管理者提供**可追溯、结构化**的进展记录，代替口头汇报。
- 形成"项目节点档案"，结项时可直接汇总成结项报告的基础版本。
- 结合 AI 助手，可实现"基于已有汇报生成草稿、自动关联任务 / 资料、提醒截止日"等辅助能力。

## 汇报周期（由项目设置决定）

常见周期：**每周 / 每两周 / 每月 / 每季度**。
项目创建时由 owner 或 advisor 指定，后续可在"项目设置"中修改。

## 汇报单典型结构

| 模块 | 填写内容 |
| --- | --- |
| 基本信息 | 项目名称、汇报周期、提交人、提交时间。 |
| 本期完成情况 | 关键任务、完成度、产出物（链接到任务、资料附件）。 |
| 存在的问题 / 风险 | 技术、物资、进度、人力等方面的问题，可关联"问题登记"。 |
| 下期计划 | 下一周期关键任务、里程碑、需要的支持。 |
| 其他说明 | 补充自由文本。 |

如果项目启用了"项目树"，汇报可以按节点汇总进度，自动根据子任务完成情况计算节点进度（具体算法由业务约定）。

## 提交流程（框架）

1. 项目详情 → "进度汇报" Tab → "新增本期汇报"。
2. 平台会自动拉取"当前周期内已完成的任务"作为草稿基础信息，成员在草稿上补充文字即可。
3. 提交后，汇报状态变为"待点评"。
4. 负责人 / 教师 / 管理员在"点评与审核"Tab 中查看汇报：
   - **确认通过**：记录点评，可附带文字反馈。
   - **退回修改**：给出退回理由，提交人补充后再次提交。

## 逾期与提醒

- 汇报截止日前（例如 1 天前）会在"通知中心 + 我的待办"中提醒。
- 逾期未交：按项目设置决定是否阻塞后续任务提交（可选策略，落地时再确认）。
- AI 助手可主动提醒"您在 N 个项目中有即将到期的进度汇报"。

## 汇报数据的使用

- 项目概览中的"整体进度"可基于最近若干次汇报与任务完成率综合展示。
- 结项阶段，可汇总历次汇报生成"项目大事记 / 结项草稿"。
- 审计维度：汇报内容不可匿名提交，提交记录与点评记录可在管理中心 - 操作审计中查询。

## 常见问题（框架）

| 问题 | 建议答复 |
| --- | --- |
| 本期没做什么，可以不交吗？ | 建议仍然提交，简要说明"本期无重大进展 + 原因"，避免系统认为逾期。 |
| 汇报能修改吗？ | 已提交但未点评前通常可撤回修改；点评通过后修改需要管理员或负责人授权。 |
| 汇报是否算考核？ | 视课题组内部管理要求；平台默认只做记录与提醒，不提供考核分数功能。 |
| 汇报内容只有本项目的人能看到吗？ | 是的，默认仅项目成员与相关管理员可见；observer 权限可能只读，按具体配置定。 |
