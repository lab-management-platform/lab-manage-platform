# 项目任务与协作流程

## 任务模块定位

任务是"项目进度"的最小度量单位。负责人 / 组长创建任务，成员更新状态并提交进展，最终由负责人或教师确认验收。

## 任务信息结构（典型字段）

| 字段                                    | 说明                                               |
| --------------------------------------- | -------------------------------------------------- |
| 标题                                    | 简洁描述本次任务目标。                             |
| 所属项目 / 所属阶段（或所属项目树节点） | 任务归属。                                         |
| 负责人 / 执行成员                       | 任务最终责任人。                                   |
| 优先级                                  | 低 / 中 / 高 / 紧急。                              |
| 截止时间                                | 计划完成日期，用于逾期提醒与待办聚合。             |
| 验收要求                                | 文本描述：期望交付物、判定是否完成的标准。         |
| 关联资料 / 附件                         | 资料文件或外链（SOP、原始数据、代码仓库等）。      |
| 状态                                    | 待分配、进行中、已提交、需要修改、已验收、已取消。 |

## 协作流程（框架）

```
创建任务 → 分配成员
    ↓
成员查看"我的任务"
    ↓
成员上传资料 / 提交进展 / 填写问题
    ↓
负责人或教师：
   ├─ 确认通过 → 任务状态：已验收
   └─ 退回修改 → 成员再次提交
```

## 各角色动作

| 角色                | 典型动作                                                                           |
| ------------------- | ---------------------------------------------------------------------------------- |
| owner / leader      | 创建任务、设置截止时间、分配成员、批量调整优先级、验收或退回。                     |
| member              | 在"我的任务"中筛选自己的任务；更新任务状态；上传资料附件；提交进展说明；填报问题。 |
| advisor / professor | 查看任务全景；在"点评与审核"中给出点评意见；必要时退回或确认。                     |
| admin / lab_admin   | 查看平台所有项目的任务分布（用于治理）；不开箱即用分配任务。                       |

## 我的任务（工作台入口）

- 工作台"我的待办"会聚合：
  - 本周到期 / 已逾期任务
  - 被退回、需要修改的任务
  - 等待点评 / 验收的任务
- 支持"一键跳转到项目详情 - 任务 Tab"，并定位到具体任务。

## 任务与项目树的关系

- 若项目启用了"项目树"（结构化实验节点 / 研究路线树），任务可以挂在某个具体节点下。
- 项目树提供"节点级进度汇总"：子节点全部完成后，父节点自动更新进度（或由 owner 手动确认，具体实现再定）。

## 常见问题（框架）

| 问题                     | 建议答复                                                       |
| ------------------------ | -------------------------------------------------------------- |
| 任务分配错了人怎么办？   | owner / leader 可进入任务详情重新指派人。                      |
| 截止时间能延期吗？       | 可以，由 owner / leader 调整并备注延期原因（建议留痕）。       |
| 任务可以批量导入吗？     | 首版可能暂不支持；可通过"项目模板 + 任务模板"实现快速创建。    |
| 一个任务可以分配多人吗？ | 业务约定待确定；通常建议一人一任务或拆分子任务，避免职责不清。 |
