# 管理中心：物资类别与审计日志

## 一、物资类别（类别设置）

### 谁维护

- `lab_admin`（主要维护者）、`admin / super_admin`。
- 普通成员不能修改物资类别。

### 物资类别字段

| 字段                 | 说明                                                     | 备注                                   |
| -------------------- | -------------------------------------------------------- | -------------------------------------- |
| 类别名称             | 如：细胞培养耗材、通用化学试剂、仪器设备                 | 命名规范统一，避免同义词重复。         |
| 是否归还             | 耗材 = 否；器材 = 是                                     | 直接决定后续流程（申请领用 vs 借还）。 |
| 计量方式             | 个 / 盒 / 瓶 / 台 / 套                                   | 申请单、台账、库存都用该单位展示。     |
| 序列号要求           | 开关（是否一物一码）                                     | 器材类建议开启，耗材类一般不开启。     |
| 动态属性（扩展字段） | 类别级自定义字段，如浓度、纯度、规格、厂家、型号、保质期 | 用于搜索、申请时精确描述。             |
| 预警阈值（默认）     | 该类别下物资的默认低库存阈值                             | 可被具体物资条目覆盖。                 |

### 维护流程（框架）

1. 新增物资类别时，先确认"是否归还"与"计量方式"无误，这两个字段后续不建议频繁修改。
2. 如类别已有存量物资，修改计量方式或序列号要求可能会造成历史数据语义变化，需要管理员手动校验。
3. 删除类别前：必须确保类别下没有未完成的申请 / 借用单；否则无法删除（或仅标记停用，按实际实现）。

## 二、操作审计日志

### 为什么要有审计

- 安全合规：谁在什么时候做了什么，可追溯。
- 故障排查：发现数据异常时，能回溯谁的操作导致。
- 流程优化：识别高频操作、遗漏节点。

### 管理中心能查的典型事件（示例，不完整）

| 模块        | 审计事件 `action`（命名约定）                                                                         | 说明                                                                 |
| ----------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 登录 / 账号 | `auth.login`、`auth.change_password`、`auth.reset_password`                                           | 登录、改密、重置密码。                                               |
| 成员管理    | `user.created`、`user.role_changed`、`user.deactivated`                                               | 成员被创建 / 调角色 / 停用。                                         |
| 项目        | `project.created`、`project.approved`、`project.archived`                                             | 项目创建 / 立项通过 / 归档。                                         |
| 任务        | `task.created`、`task.assigned`、`task.status_updated`                                                | 任务创建 / 分配 / 状态变更。                                         |
| 物资        | `inventory.application_submitted`、`inventory.application_approved`、`inventory.application_rejected` | 申请提交 / 批准 / 拒绝。                                             |
| 物资        | `inventory.stock_in`、`inventory.stock_out`、`inventory.borrow`、`inventory.return`                   | 出入库、借还动作。                                                   |
| 文件        | `file.uploaded`、`file.shared`（若启用共享）                                                          | 文件上传 / 共享。                                                    |
| 会议        | `meeting.created`、`meeting.minutes_submitted`                                                        | 会议创建、纪要提交。                                                 |
| AI 助手     | `ai.chat.completed`                                                                                   | 一次 AI 对话完成（可记录 prompt 长度、引用来源数，不记录敏感内容）。 |
| AI 知识库   | `ai.knowledge.created`、`ai.knowledge.updated`、`ai.knowledge.deleted`                                | 知识库文档的增删改。                                                 |
| 管理中心    | `admin.category_created`、`admin.category_updated`、`admin.role_template_changed`                     | 管理中心的配置变更。                                                 |

### 审计查询条件

管理中心审计查询页建议支持：

- 时间范围（默认最近 7 天）
- 操作人（actorId）
- 动作类型（action）
- 目标类型 + 目标 ID（如 target_type = "ai_knowledge", target_id = "xxx"）

### 原则

- 审计日志**只能追加、不可删除、不可修改**。
- 审计日志不记录明文密码、密钥、新密码本身。
- 审计日志的读取权限仅对 `admin / super_admin / 指定审计角色` 开放；`lab_admin` 可看到与其业务相关部分，具体按策略。

## 常见问题（框架）

| 问题                                               | 建议答复                                                                         |
| -------------------------------------------------- | -------------------------------------------------------------------------------- |
| 某条物资入库错了，审计日志能帮我找到是谁操作的吗？ | 能。按 target_type / 动作名 / 时间范围检索 `inventory.stock_in` 即可定位操作人。 |
| 我想导出最近一个月的所有审批操作？                 | 管理中心审计页一般提供导出；若首版不支持，由管理员在数据库侧查询导出。           |
| 审计日志保留多久？                                 | 按合规与存储策略约定，建议 ≥ 6 个月，重要审计可 ≥ 1 年。                         |
| 普通用户能看自己的审计日志吗？                     | 默认不开放完整审计查询；但若用户询问"我是否做过某操作"，管理员可代为查询。       |
