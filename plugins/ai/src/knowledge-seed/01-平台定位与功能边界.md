# 平台定位与功能边界

## 平台是什么

实验室管理平台是一个面向**高校实验室、课题组、实验项目成员**的项目制协作系统。
以"**项目 / 课题组**"为主线，串联 7 大核心业务：

1. 账号与角色权限
2. 项目管理（任务、资料、树、进度汇报）
3. 物资管理（耗材 / 器材）
4. 文件资料与知识库
5. 会议与通知
6. AI 助手（答疑 + 业务操作工具调用）
7. 管理中心（系统治理）

## 平台不是什么

- 不是学校级统一身份认证（SSO）平台。当前仅支持本地账号（username + password）登录。
- 不是 ERP / 财务系统。物资模块不包含发票、付款、预算审批等财务功能。
- 不是 LIMS（实验室信息管理系统）。不做样品、批次、测序、仪器联机等强实验数据管理。
- 不是在线代码/IDE 平台。实验代码仓库通过"项目详情 → 项目文档地址 / 仓库地址"外链方式接入。

## 顶层能力一览

| 模块 | 能做什么 | 典型入口 |
| --- | --- | --- |
| 工作台 | 我的概览、待办聚合、通知中心、快捷提交 | 首页 |
| 项目管理 | 创建项目、分配任务、提交进展、进度汇报、点评审核 | 项目 / 项目详情 |
| 物资管理 | 耗材目录、申请审批、入库出库、器材借还、逾期提醒 | 物资 |
| 文件资料 | 公共资料、项目资料、NAS 索引、版本、共享权限 | 资料与知识库 |
| 会议通知 | 会议日历、参会、请假、纪要、通知收件箱 | 会议与通知 |
| AI 助手 | 知识库答疑、业务数据查询、辅助操作（需用户确认） | AI 助手 |
| 管理中心 | 成员目录、小组、角色模板、物资类别、操作审计 | 仅 admin / lab_admin |

## 能力边界与建议

- 平台中的**关键写操作**（审批、入库、创建项目等）默认**不会自动执行**，AI 助手会先给出建议与参数摘要，**由用户在界面二次确认后才落地**。
- 涉及实验原始数据、财务/人事/涉密类信息，请先在课题组内部确认合规性后再使用对应功能。
- 如遇到功能未覆盖的场景，优先使用"项目资料"上传附件 + "项目笔记"描述的方式保存上下文。
