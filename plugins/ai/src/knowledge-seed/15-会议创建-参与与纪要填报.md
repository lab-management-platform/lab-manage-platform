# 会议创建、参与与纪要填报

## 会议模块定位

会议模块覆盖：会议日历、会议创建、参会与请假、纪要填报、项目上下文关联。

## 典型入口

- 会议与通知 → 会议日历（按月 / 周查看）。
- 会议与通知 → 会议列表（按状态、项目、参与人筛选）。
- 项目详情 → "项目会议"（只看项目相关会议）。

## 创建会议

### 谁能创建

- 平台内任意登录用户理论上都可以创建；但是否能邀请全平台成员取决于组织策略。
- 建议默认：**项目 owner / leader / professor / admin** 创建与项目强相关的会议；student 创建个人或小组级会议。

### 会议字段（框架）

| 字段                           | 说明                                            |
| ------------------------------ | ----------------------------------------------- |
| 标题                           | 必填，简洁。                                    |
| 开始 / 结束时间                | 必填，建议给出提前余量。                        |
| 地点（线下）或会议链接（线上） | 必填或二选一。                                  |
| 参与人                         | 多选用户列表；支持邀请 observer（如外部评审）。 |
| 关联项目                       | 可选；若填写，会在项目详情的"项目会议"中出现。  |
| 议题 / 议程                    | 1 个或多个议题，可列出议题负责人。              |
| 需要准备的资料                 | 可附件或链接到项目资料 / 公共资料。             |
| 纪要负责人                     | 指定一人负责会后撰写纪要（避免没人写）。        |
| 提醒设置                       | 会前 1 天 / 1 小时等自动提醒。                  |

## 参与与请假

- 创建会议后，参与人会在"通知中心 + 我的待办"看到待确认的会议邀请。
- 参与人可做的动作：
  - 确认参加
  - 请假（附理由）
  - 拒绝（附理由，对不相关邀请）
- 请假超过阈值或关键角色请假时，建议创建者考虑是否延期。

## 纪要填报

### 提交时间建议

**会议结束后 24 小时内**由纪要负责人完成。

### 纪要模板（建议结构，可在公共资料放模板）

1. 基本信息：会议标题、时间、地点、参会人 / 请假人。
2. 议题讨论要点：按议题逐条记录。
3. 形成的决议 / 任务分配（"谁 + 什么事 + 截止日"三件套）。
4. 下次会议时间 / 议题预告（如有）。
5. 附件：PPT、截图、相关资料链接。

### 纪要与任务的联动（框架能力，落地实现再定）

- 若纪要中明确了任务分配，可在会后一键生成"项目任务"草稿，避免口头约定漏掉。

## 会议状态

| 状态                | 含义                         |
| ------------------- | ---------------------------- |
| 计划中（scheduled） | 已创建、等待召开。           |
| 已完成（completed） | 会议已结束，纪要通常已提交。 |
| 已取消（cancelled） | 因故取消。                   |

## 常见问题（框架）

| 问题                       | 建议答复                                                                       |
| -------------------------- | ------------------------------------------------------------------------------ |
| 邀请了不该邀请的人怎么办？ | 创建者或管理员进入会议详情移除参与人，可补发取消通知。                         |
| 时间冲突能自动发现吗？     | 框架建议实现"创建会议时校验参与人日历是否已有会议"；首版若不支持，可手动沟通。 |
| 纪要没提交影响什么？       | 会在"会议与通知 - 待提交纪要"里提醒，并出现在负责人的待办中。                  |
| 可以创建周期性会议吗？     | 框架建议后续支持；首版可能不支持，可先多次创建或用模板复用。                   |
