# 项目目录与项目创建

## 模块定位

项目是平台的**业务主线**。所有任务、物资申请、文件资料、会议、AI 上下文都通过 `project_id` 与项目关联。

## 项目目录（项目列表）

- 入口：顶部侧边栏"项目"。
- 默认视图：列出"我参与 / 我负责 / 我关注"的项目，支持按状态、周期、负责人、课题组筛选。
- 项目卡片展示内容：项目名称、负责人、状态、周期、整体进度（任务完成率或最近一次汇报得分，待实现后明确）。
- 搜索：支持按项目名称 / 编号 / 关键词模糊查找。

## 项目状态（建议枚举，落地后可能调整）

| 状态   | 含义                                     |
| ------ | ---------------------------------------- |
| 草稿   | 项目信息未填写完整，未提交立项。         |
| 待立项 | 已提交立项申请，等待审批。               |
| 进行中 | 立项通过，任务与协作正常进行。           |
| 暂停   | 项目临时冻结，不允许新的提交与进度更新。 |
| 已结项 | 项目完成并归档，后续只读可查。           |
| 已终止 | 提前终止的项目，保留历史数据。           |

## 项目创建 / 立项流程（框架）

1. 项目目录页点击"创建项目"。
2. 填写项目基本信息：
   - 项目名称（必填）
   - 项目编号（若系统自动生成则无需手动填）
   - 负责人（默认创建者，可改）
   - 起止时间（周期）
   - 所属课题组 / 实验室
   - 项目文档地址、项目仓库地址（URL，可选；项目详情页会提供跳转按钮）
   - 简介 / 研究背景
3. 指定初始成员与项目角色（owner / leader / member / advisor / observer）。
4. 选择项目模板（可选）：若管理员配置了"项目角色模板 / 任务模板 / 汇报模板"，可直接套用。
5. 保存为"草稿"或直接"提交立项"。
6. 立项审批通过后，项目进入"进行中"状态，可开始任务协作与资料上传。

## 项目详情页结构

进入项目详情后，通常包含以下子页 / Tab：

- **概览**：项目基本信息、进度总览、文档 / 仓库跳转按钮、最近动态。
- **任务**：任务列表、看板视图（待分配 / 进行中 / 已完成 / 已验收）。
- **项目树**：结构化任务树 / 实验节点树（业务约定，待具体实现）。
- **进度汇报**：按周期（周 / 双周 / 月 / 季）提交汇报，负责人或教师点评。
- **成员与角色**：成员列表、角色调整、新增成员。
- **项目资料**：项目私有文件、版本、标签。
- **项目物资**：关联项目的耗材申请、器材借还记录。
- **项目会议**：项目相关会议日历与纪要。
- **点评与审核**：集中查看退回 / 确认 / 点评记录。
- **项目设置**：基本信息、归档 / 关闭、模板设置等。

## 常见问题（框架）

| 问题                      | 建议答复                                                                                        |
| ------------------------- | ----------------------------------------------------------------------------------------------- |
| 谁能创建项目？            | 按角色约定，通常 professor / lab_admin / admin 可直接创建；student 能否创建由管理中心配置决定。 |
| 创建后能否删除？          | 不建议物理删除；一般走"草稿废弃 / 终止 / 归档"流程，保留审计记录。                              |
| 如何切换项目上下文？      | 顶部面包屑 / 当前项目选择器，切换后相关页面自动带上该 project_id。                              |
| 能克隆 / 复用已有项目吗？ | 首版不一定提供；可在管理中心配置"项目模板"实现类似能力。                                        |
