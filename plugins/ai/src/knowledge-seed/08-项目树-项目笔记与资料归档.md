# 项目树、项目笔记与资料归档

## 项目树（结构化实验路线 / 任务骨架）

### 是什么

"项目树"是项目的结构化骨架，用于表示：

- 研究路线 / 技术路线的层级关系
- 实验节点（目标 → 子目标 → 动作）
- 每个节点挂载任务、资料、问题与汇报记录

### 适用场景

- 大型科研项目（多个阶段、多个分支、依赖关系）。
- 标准化流程（如固定的实验流水线，可复用为模板）。
- 结项回顾时，希望按节点汇总"做了什么、遇到什么问题、产出什么"。

### 与任务的关系

- 一个节点可挂多个任务；节点进度可由下属任务 / 子节点自动汇总（算法待实现确认）。
- 不使用项目树时，任务直接挂在项目根下，不影响其他功能。

## 项目笔记

### 定位

"项目笔记"是团队围绕项目的**轻量、可检索**的日常记录集合，不是正式的汇报文档。

### 典型用途

- 实验过程中的随手记录、异常现象、参数调整。
- 组会讨论要点、brainstorming 记录。
- 临时 Todo / 灵感记录。
- SOP 的草稿版本（完善后再归档到"项目资料"或"公共资料"）。

### 建议使用方式

- 笔记默认"项目成员可见"。
- 重要、定稿的内容请从"笔记"中整理后，上传为正式资料（带版本号）或写入"AI 知识库文档"，便于答疑引用。
- 笔记支持标签、时间筛选、全文搜索（按具体实现落地）。

## 项目资料（归档）

### 资料分类

| 分类     | 说明                           | 存储位置建议                               |
| -------- | ------------------------------ | ------------------------------------------ |
| 立项文档 | 立项申请书、审批记录、伦理相关 | 项目资料                                   |
| 会议资料 | 组会 PPT、纪要 PDF、外链       | 项目资料 + 会议纪要关联                    |
| 实验 SOP | 标准操作流程、版本化           | 项目资料；定稿后同步到公共资料或 AI 知识库 |
| 原始数据 | 测序 / 仪器 / 采集文件         | NAS 索引（避免在业务库中存大文件）         |
| 分析结果 | 图表、分析结果文件             | 项目资料 + 版本                            |
| 结项材料 | 结项报告、汇报视频 / 幻灯片    | 项目资料                                   |

### 版本与引用

- 资料建议保留上传版本，避免覆盖丢失；平台会记录上传人、上传时间、版本号。
- AI 助手中引用资料时，会展示"文档标题 + 上传版本 + 来源链接"，便于跳转核验。

## 归档策略（框架）

- 项目状态变为"已结项 / 已终止"后，项目下的笔记、资料、汇报、任务进入只读模式，不再允许新增或修改。
- 归档内容仍可查询、下载，用于审计、复盘、新项目参考。
- 归档时机建议在"项目结项审批通过后"自动触发，或由 owner / 管理员手动触发。

## 常见问题（框架）

| 问题                       | 建议答复                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------ |
| 项目树可以导入吗？         | 可考虑后续支持 JSON / Markdown 大纲导入；首版一般手动编辑。                          |
| 笔记会同步到 AI 知识库吗？ | 不会自动同步。笔记内容偏非正式；如需要作为答疑依据，请在 AI 知识库管理页面手动添加。 |
| 资料文件太大传不上？       | 大文件建议存储到 NAS，平台提供"NAS 索引"功能记录路径，不建议直接上传超大附件。       |
| 归档后发现资料错了？       | 由管理员或项目 owner 临时"恢复项目"，修正后再次归档，保证过程可追溯。                |
