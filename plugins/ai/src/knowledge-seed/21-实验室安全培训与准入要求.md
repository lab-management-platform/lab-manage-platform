# 实验室安全培训与准入要求

## 定位

本文档为**框架性条目**。实验室具体的培训内容、准入资质、有效期请由教授 / 安全员在"公共资料"和"AI 知识库"中补充正式版本；在正式版本补充前，用户询问时 AI 会以"未在知识库查找到相应操作，酌情采纳"作为提示。

## 建议覆盖的培训类别

| 类别 | 说明 | 建议的最低考核方式 |
| --- | --- | --- |
| 实验室基础安全 | 水电、消防、化学品基本认知、应急通道、紧急洗眼器 / 喷淋位置 | 在线题库考试 + 现场导览签到。 |
| 化学品安全 | MSDS 阅读、强酸强碱 / 易制毒 / 易燃易爆存储、分装、泄漏处置 | 考试 + 操作演示。 |
| 生物安全（如适用） | 微生物 / 细胞系 / 实验动物相关规范、生物废弃物分类处理 | 专项培训与准入。 |
| 辐射 / 激光 / 高压类（如适用） | 仪器相关专项安全培训、佩戴个人辐射计等 | 专项资质备案。 |
| 废弃物处置 | 分类（尖锐 / 化学 / 生物 / 普通）、容器、标签、暂存、交接记录 | 考试 + 实操签到。 |
| 紧急情况演练 | 火灾、化学品溅到皮肤 / 眼睛、受伤、地震等 | 定期演练 + 签到。 |

## 准入要求（建议）

1. **新成员准入**：
   - 入职 / 进组前必须完成"基础安全 + 废弃物处置"两类培训并考核通过。
   - 在平台"成员目录"中标记培训通过状态、通过日期、有效期（若按年份要求复训）。
2. **专项准入**：
   - 要使用某台高风险仪器（高压釜、激光、生物安全柜、辐射类设备），必须先持有对应的专项培训合格记录。
   - 管理员可在"设备台账 / 仪器预约"（若实现）中校验准入，不具备准入的成员 AI 也会在答疑中提示："该设备需先通过 XX 专项培训后使用，建议联系安全员确认。"

## 培训记录管理建议

- 记录字段（框架）：
  - 成员、培训类别、培训日期、考核结果（通过 / 未通过）、有效期至、培训负责人。
- 存储位置（建议后续实现的两种方案）：
  - 方案 A：管理中心新增"安全培训"Tab 管理。
  - 方案 B：在"公共资料"放电子版签到与成绩册 + AI 知识库维护常见问答。正式记录（合格名单）由管理员保存在内部系统。

## 违规与复核

- 出现未遵守规范的情况：
  - 首次：提醒 + 专项补课。
  - 多次：限制进实验室权限、暂停物资申请、直至重新通过培训与审核。

## 与 AI 助手的结合

- AI 在回答"某台设备怎么用？""某类化学品怎么存？"这类问题时：
  - 先给出制度 / SOP 层面的流程说明；
  - 自动追加安全提醒："使用前请确认您已通过对应专项培训并持有准入资质。"
  - 若知识库中没有正式培训记录管理流程的记载，则按兜底话术标注："未在知识库查找到相应操作，酌情采纳。"

## 常见问题（框架，待正式版本补全）

| 问题 | 建议答复 |
| --- | --- |
| 安全培训多久一次？ | 建议基础安全每年复训；专项培训按实验室具体要求。 |
| 没做过培训能进实验室吗？ | 不建议；请先联系负责人 / 安全员安排培训与考核。 |
| 培训记录在哪里看？ | 请联系 lab_admin 或查看"公共资料 - 安全培训文档"（若已上传）。 |
| 外单位来做实验需要培训吗？ | 需要，且通常必须有本实验室成员陪同。 |
