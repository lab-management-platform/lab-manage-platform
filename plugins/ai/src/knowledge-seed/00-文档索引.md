# 实验室管理平台答疑知识库 - 文档索引

本目录为 AI 助手答疑模块的种子知识文档，用于构建 `ai.knowledge_document` 表的初始内容。
所有文档均为 Markdown 格式，按业务模块拆分，便于后续补充与版本维护。

| 分类（category） | 说明 | 对应一级导航 |

| 物资管理 | 耗材申请、审批、入库、出库、器材借还、逾期 | 物资 |
| 文件资料与知识库 | 文件上传、版本、权限、知识库维护 | 资料与知识库 / AI 助手 |
| 会议与通知 | 会议创建、参会、纪要、通知收件箱 | 会议与通知 |
